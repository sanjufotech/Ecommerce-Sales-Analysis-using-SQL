 Ecommerce-Sales-Analysis-using-SQL
E-commerce transaction data using SQL to uncover business insights related to sales performance, customer behavior, product demand and country-wise revenue.  


Project Overview

This project analyzes e-commerce transaction data using SQL to uncover business insights related to sales performance, customer behavior, product demand, and country-wise revenue.

The analysis was performed using SQLite and covers data cleaning, aggregation, filtering, subqueries, views, and indexing techniques commonly used by Data Analysts.

 Objective

The objective of this project is to:

* Analyze customer purchasing behavior
* Identify top-selling products
* Calculate revenue trends
* Find high-value customers
* Compare sales across countries
* Practice real-world SQL querying techniques

Tools Used

* SQL
* SQLite Online
* GitHub
* Kaggle Dataset

 Dataset

Dataset Source:
https://www.kaggle.com/datasets/carrie1/ecommerce-data

Dataset contains:

* Invoice Number
* Product Information
* Quantity Sold
* Unit Price
* Customer ID
* Country
* Invoice Date

Data Cleaning

Performed the following cleaning steps:

* Removed records with NULL Customer IDs
* Verified row counts
* Checked data consistency

 Key Insights

* Identified products generating the highest sales volume.
* Found customers contributing the largest share of revenue.
* Analyzed monthly revenue trends to understand seasonality.
* Compared country-wise sales performance.
* Demonstrated SQL optimization using indexes.


Conclusion

This project demonstrates how SQL can be used to extract meaningful business insights from transactional data. It showcases data cleaning, aggregation, subqueries, views, and indexing techniques that are frequently used in Data Analyst roles.
